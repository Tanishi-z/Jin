WHY JIN

Learn the process,
not just the answer.

Jin does not leave everything to one model. Shogi-inspired agents contribute perspectives on requirements, experience, engineering, and quality, while Kin orchestrates the whole formation.

It independently reconstructs concepts seen in Claude Code as of July 2026—including agents, skills, hooks, and project context—for hands-on learning and experimentation.

01

Fully local

Runs with Ollama. Try it in your own environment without sending requirements or code to an external API.

02

Separated by role

Seven pieces cover specialized domains, exposing a workflow built around multiple perspectives and review.

03

Extensible mechanics

Define agents, skills, and hooks as files, then evolve Jin around your own development workflow.

HOW IT WORKS

From vision to implementation.

  1. 一
    REQUEST

    Describe the request

    Enter even a rough idea using natural language.

  2. 二
    FORMATION

    Build the formation

    Kin reads the request and selects the specialists it needs.

  3. 三
    REVIEW

    Refine from every angle

    Each piece analyzes the idea, and Kin reviews and combines their proposals.

  4. 四
    IMPLEMENT

    Review and implement

    Promoted pieces generate code and documents for review before changes are applied.

LEARNING TOOL

Not a replacement
for Claude Code.

Jin is neither an official Anthropic or Claude Code project nor a fully compatible implementation. It is an experimental environment for observing agentic development concepts locally and learning by building.

See the supported scope in the README →

GET STARTED

Make your
first move.

All you need is Node.js 24 or later and Ollama.

git clone https://github.com/Tanishi-Zukka/Jin.git
cd Jin && npm install && npm run build
npm install -g . && jin

To try only the UI, run jin --demo
