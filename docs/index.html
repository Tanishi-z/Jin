WHY JIN

答えではなく、
考え方を学ぶ。

Jinは、ひとつのモデルにすべてを任せません。要求整理、体験設計、技術設計、品質評価。それぞれの視点を持つ駒が協調し、金が全体を統合します。

2026年7月時点のClaude Codeに見られるエージェント、スキル、フック、プロジェクトコンテキストなどの概念を、学習・実験のために独自再構成しています。

01

完全ローカル

Ollamaで動作。要求やコードを外部APIへ送信せず、自分の環境で試せます。

02

役割で分ける

7つの駒が専門領域を担当。複数視点による分析とレビューの流れを体験できます。

03

仕組みを拡張

エージェント、スキル、フックをファイルで定義し、自分の開発フローへ育てられます。

HOW IT WORKS

構想から実装まで。

  1. 一
    REQUEST

    要求を伝える

    まだ曖昧なアイデアでも、自然な言葉で入力します。

  2. 二
    FORMATION

    布陣を組む

    金が要求を読み、必要な専門エージェントを選びます。

  3. 三
    REVIEW

    多角的に磨く

    各駒が分析し、金のレビューを通して提案を統合します。

  4. 四
    IMPLEMENT

    確認して実装する

    成り駒がコードや文書を生成し、差分確認後に適用します。

LEARNING TOOL

Claude Codeの
代替ではありません。

JinはAnthropicおよびClaude Codeの公式プロジェクトではなく、完全互換実装でもありません。エージェント型開発の考え方をローカルで観察し、手を動かして学ぶための実験環境です。
